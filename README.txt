Jeu de Tarot x Stake (Prototype)
==================================

Ce jeu est une version simplifiée du tarot français inspirée des mécaniques de jeu Stake.
Le joueur mise une somme en crypto (BTC/ETH), tire 3 cartes, et gagne selon des combinaisons prédéfinies.

Fichiers :
- index.html : interface du jeu
- style.css : style de la page
- tarot.js : logique de tirage et calcul des gains

Fonctionnalités :
- Tirage aléatoire de 3 cartes
- Affichage de la main et du résultat
- Calcul des gains avec multiplicateur

Prochaine étape :
- Connexion Metamask (wallet)
- Paiements réels via Web3.js ou Ethers.js
